REMS-ROZKLAD v2.0.11 — розподіл дисципліни по групах

Додано новий швидкий режим у вкладці «Навантаження».

1. Дисципліна тепер може бути центром розподілу, а не лише конкретна група.
2. «Групи окремо»: на одному екрані видно всі групи цієї дисципліни та можна одразу призначити різних викладачів і години кожній групі.
3. Можна одним кліком поставити одного викладача всім позначеним групам, а потім точково змінити окремі групи.
4. «Спільний потік»: вибрати кілька груп, викладача та кількість годин — система створить потік для цього виду занять.
5. Лекції, практичні, семінари та інші неперсональні види занять можуть мати різну схему груп.
6. Існуючий детальний редактор навантаження по конкретній групі збережено.
7. Система перевіряє планові години, уже виставлені заняття та не дозволяє перевищити план.
8. .nojekyll збережено для стабільного GitHub Pages.
