# РЕМС-РОЗКЛАД v1.0.8 — календар + робоча картка дня

Тепер календар постановки розкладу працює як основне робоче місце.

## Логіка

1. Обираєш місяць.
2. Натискаєш конкретну дату в календарі.
3. Праворуч одразу відкривається повна робоча картка цього дня.

У картці дня видно:
- скільки занять цієї дисципліни вже стоїть;
- скільки інших занять уже має викладач;
- скільки інших занять уже має група;
- таблицю всіх пар дня;
- що стоїть у викладача на кожній парі;
- що стоїть у групи на кожній парі;
- групу / викладача / дисципліну / аудиторію зайнятого слота.

Нижче в тій самій картці можна додати одну або одразу кілька пар:
- вид заняття;
- номер пари;
- аудиторія;
- охоплення;
- примітка.

Після збереження години автоматично списуються з розподіленого навантаження
відповідного виду.

На широкому екрані:
- календар ліворуч;
- робоча картка вибраного дня праворуч і залишається перед очима.

На вузькому екрані картка переходить під календар.
