# РЕМС-РОЗКЛАД v1.0.2 — синхронізовані готові календарі

Виправлено спільне джерело проблеми для готового розкладу групи та індивідуального розкладу викладача.

## Що виправлено
- Старі записи розкладу нормалізуються: група відновлюється через дисципліну, `teacherId` — через унікальний профіль викладача.
- Готовий розклад групи використовує відновлену групу, тому старі заняття не губляться через порожнє/застаріле поле `group`.
- Адміністраторський індивідуальний розклад викладача знаходить також старі заняття, де був збережений викладач текстом.
- Якщо актуальний тиждень порожній, при першому відкритті календар переходить на найближчий тиждень, де реально є заняття.
- Якщо на поточному тижні заняття є — календар залишається на поточному тижні.
- У готовому розкладі є список «Тижні з заняттями».
- Такий самий список додано в індивідуальний розклад викладача.
- У викладацькому календарі видно загальну кількість занять викладача у базі і кількість подій відкритого тижня.
- Нормалізовані зв’язки автоматично повертаються в хмару для адміністратора/диспетчера, щоб старі записи поступово стали повноцінними.
