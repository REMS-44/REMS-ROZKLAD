# РЕМС-РОЗКЛАД v0.2

Що додано:
- редагований довідник **видів занять**;
- правила підрахунку: аудиторні/парами, за контингентом, індивідуально кожному студенту, фіксовані, ручні;
- розширені профілі викладачів;
- дисципліни з навчальним роком, семестром, групою, викладачами, формою контролю, кольором і годинами за видами занять;
- міграція даних з попередньої версії v0.1 через localStorage.

Замініть у репозиторії файли:
`index.html`, `styles.css`, `app.js`, `data.js`.

Поточна версія зберігає зміни локально в браузері.
