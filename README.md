# РЕМС-РОЗКЛАД v1.0.22

Кафедральна **«Серія дат»** тепер працює за тією самою логікою,
що й «готові пари» інших кафедр.

## У «Розставити навантаження»

Як і раніше, спочатку видно тільки:
- **Одна дата**
- **Серія дат**

Після вибору «Серія дат» є два способи створити список.

### 1. Конкретні дати
Можна вставити:
`03.09, 10.09, 17.09, 24.09`

### 2. Згенерувати за правилом
Можна задати:
- щотижня / через тиждень;
- день тижня;
- період «від / до».

## Після створення дат

Кожна дата — окремий рядок.

Для КОЖНОЇ дати можна незалежно змінити:
- дату;
- вид заняття;
- номер пари;
- аудиторію;
- включити / виключити її із серії.

Тобто можна задати «2 пара для всіх», але одну конкретну дату
переставити на 3-тю пару.

## Масові дії

Для всієї серії можна задати:
- вид заняття;
- пару;
- аудиторію;

і натиснути **«Застосувати до всіх»**.

Також залишається:
**«Автозаповнити види за залишком»**.

Система автоматично розподіляє доступні лекційні / практичні /
лабораторні години по датах, не виходячи за розподілене навантаження.

## Контроль

На відміну від готових некафедральних пар, кафедральна серія:
- списує години з навантаження;
- контролює залишок кожного виду;
- перевіряє зайнятість групи;
- перевіряє зайнятість викладача;
- перевіряє аудиторію;
- перевіряє доступність викладача;
- не дозволяє зберегти дубль однієї дати + пари всередині серії.
