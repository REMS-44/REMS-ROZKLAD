# РЕМС-РОЗКЛАД v1.0.16 — компактний «Журнал занять»

Нескінченну таблицю «Виставлені заняття» замінено на адміністративний
**Журнал занять**.

## За замовчуванням

Журнал згорнутий і займає один компактний рядок.

У заголовку видно:
- загальну кількість записів;
- кнопку «Відкрити календар»;
- кнопку «Розгорнути».

## Після відкриття

Доступні фільтри:
- місяць;
- група;
- викладач;
- дисципліна;
- джерело;
- пошук.

За замовчуванням вибирається актуальний навчальний місяць.

### Джерело
Можна окремо переглянути:
- кафедральні заняття;
- готові пари інших кафедр.

## Обмеження кількості

Одразу показується максимум 30 записів.

Якщо записів більше — унизу є:
**«Показати ще 30»**.

Тобто сторінка більше не росте безкінечно.

## Для чого журнал

Це технічний адміністративний інструмент:
- знайти конкретну пару;
- перевірити її;
- відредагувати;
- видалити.

Основним робочим інтерфейсом складання розкладу залишається календар
і розподілене навантаження зверху.
