# РЕМС-РОЗКЛАД v1.9.3.5 — видимі потоки груп

У «Складанні розкладу» → дисципліна → викладач →
«Одна дата» або «Серія» тепер є великий блок:

**ХТО СЛУХАЄ ЦЮ ПАРУ**
**Одна пара для кількох груп**

## Головна зміна

Раніше система спочатку відфільтровувала групи, які не проходили
всі умови. Тому друга група могла просто не з'явитися.

Тепер група не зникає.

Для кожної групи видно статус:

- **ОСНОВНА**
- **МОЖНА**
- **НЕ МОЖНА**

І конкретну причину, наприклад:

- немає цієї дисципліни для групи;
- дисципліна є, але в іншому семестрі;
- цьому викладачу не розподілено години;
- для вибраного виду заняття (наприклад «Практичне») години
  цьому викладачу в другій групі не розподілені.

## Динамічна перевірка

При зміні виду заняття статуси груп перераховуються одразу.

Наприклад, для «Лекції» РЕМС-34 може показувати **МОЖНА**,
а після вибору «Практичне» — **НЕ МОЖНА · Практичне не розподілено**.

## Як створити потік

Якщо РЕМС-34 має статус **МОЖНА**, просто натисни її картку.

Угорі блоку одразу буде:

**ПОТІК · РЕМС-44 + РЕМС-34**

Після збереження це одна реальна пара:
одна дата, одна пара, один викладач, одна аудиторія,
але вона відображається в обох групах.
