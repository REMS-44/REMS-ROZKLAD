# РЕМС-РОЗКЛАД v1.3.3 — точні пояснення конфліктів

Замість загального «є конфлікт» система тепер пише конкретно:
- яка аудиторія зайнята;
- ким / чим вона зайнята;
- який викладач уже має заняття;
- який студент уже має індивідуальне або консультацію;
- чи є в групи звичайна пара в цей час.

У списках аудиторій зайняті варіанти підписані:
«324а · ЗАЙНЯТА — 3 пара · РЕМС-44 · Режисура естради і шоу»

Для індивідуальних занять зайнятість аудиторії перевіряється
саме на вибрану половину пари.

Ліве меню у блоці «Розклад»:
1. Складання розкладу
2. Розклад
3. Індивідуальні
4. Аудиторії

На GitHub замінити:
- index.html

- styles.css

cloud.js і data.js не змінювалися.
