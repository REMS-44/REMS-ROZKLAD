# РЕМС-РОЗКЛАД v1.0.3 — місячний індивідуальний розклад викладача

## Змінено сторінку «Мій розклад / Розклад викладача»

Тижневий формат прибрано.

Тепер зверху є 10 вкладок навчального року:
- Вересень
- Жовтень
- Листопад
- Грудень
- Січень
- Лютий
- Березень
- Квітень
- Травень
- Червень

Після вибору місяця нижче показується весь календар місяця:
- 7 колонок Пн–Нд;
- кожен день окремою клітинкою;
- у дні видно всі заняття викладача;
- для заняття показуються № пари / час, група, дисципліна, вид заняття та аудиторія;
- поточна дата підсвічується;
- на вкладці місяця показується кількість подій;
- є кнопки «Попередній», «Наступний», «Актуальний місяць».

Важливо: заняття відображається за датою і більше не залежить від наявності коректного `pairId`.
Тому старі заняття без номера пари також не зникають із календаря.

Липень і серпень не показуються.
