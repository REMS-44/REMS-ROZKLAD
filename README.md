# РЕМС-РОЗКЛАД v1.9.2 — навчальні тижні + компактний режим «По днях груп»

- Режим бере кількість навчальних тижнів із плану курсу.
- Для 3 курсу: 5 семестр = 10 тижнів, 6 семестр = 12 тижнів.
- Є кнопка «⚙ Навчальний період»: можна вручну задати дату початку і кількість тижнів.
- І семестр за замовчуванням стартує 1 вересня, ІІ — 1 лютого.
- На десктопі всі дати вміщуються по ширині без горизонтального скролу; 11–12 тижнів автоматично стають компактнішими.
- На вузьких екранах скрол лишається, щоб текст не став нечитабельним.
- Налаштування навчального періоду синхронізується через Firebase.
