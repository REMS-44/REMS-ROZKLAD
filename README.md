# РЕМС-РОЗКЛАД v1.0.17

Виправлено порожню сторінку «Розклад викладача».

Причина:
після додавання смуг-пар і написів «вікно» календар використовував
`teacherSchedulePairs(source)`, але сама допоміжна функція була відсутня.

Через це:
- заголовок сторінки та ПІБ викладача встигали з'явитися;
- далі JavaScript зупиняв рендер;
- сам календар залишався порожнім.

Тепер функція відновлена.

Додатково перевірено всі виклики функцій з префіксом `teacher...`:
відсутніх визначень більше немає.

На GitHub достатньо замінити:
- `index.html`
- `app.js`

Інші файли не змінювалися.
