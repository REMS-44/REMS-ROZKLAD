# РЕМС-РОЗКЛАД v0.6

Головні зміни:
- навчальний план показується компактно; детальні години розкриваються лише за потреби;
- розклад тепер пов’язаний із розподіленим навантаженням;
- при виборі групи показуються тільки активовані для неї дисципліни;
- для дисципліни доступні тільки види занять, що є в її плані;
- викладачі для виду заняття підтягуються з розподілу навантаження;
- система показує: план / уже в розкладі / залишок;
- додавання заняття автоматично зменшує залишок, видалення — повертає години;
- є масове виставлення: щотижня, через тиждень або за конкретними датами;
- масове виставлення автоматично зупиняється, коли години вичерпані;
- конфліктні дати (аудиторія, група, викладач, недоступний час) пропускаються;
- зовнішні / загальноосвітні дисципліни все ще можна додавати вручну без списання кафедрального навантаження.

Для оновлення GitHub Pages замініть `index.html`, `styles.css`, `app.js`, `data.js`.
