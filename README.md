# РЕМС-РОЗКЛАД v1.9.3.2 — виправлення Word

Ця версія виправляє помилку Microsoft Word
«Сталася помилка під час спроби відкрити файл».

## Що змінено

- повністю перероблено внутрішню OOXML-структуру Word-файлу;
- властивості абзаців, шрифтів, клітинок і таблиць записуються у правильному порядку;
- додані стандартні `settings.xml`, `fontTable.xml` і `theme1.xml`;
- прибрані крихкі вертикальні та горизонтальні злиття клітинок;
- потокова пара тепер повторюється у колонках усіх груп — це також зручніше для вставлення у факультетський розклад;
- видаляються невидимі керівні символи, які можуть ламати XML після копіювання тексту;
- у Word виводяться всі 1–7 пар, навіть якщо деякі поки порожні.

## Перевірка

Перед збіркою архіву автоматично створено тестовий `.docx` з:
- двома групами;
- потоковою лекцією;
- звичайними заняттями;
- вибірковою дисципліною.

Тестовий документ:
- пройшов ZIP integrity check;
- відкрився бібліотекою python-docx;
- був реально відкритий офісним рушієм і відрендерений у сторінки через DOCX render pipeline.
