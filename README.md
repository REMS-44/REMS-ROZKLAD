# РЕМС-РОЗКЛАД v1.0.1 — виправлений готовий «Розклад»

Виправлено саме вкладку **Розклад**.

## Що змінилось
- календар читає всі заняття вибраної групи безпосередньо з `db.schedule`;
- нормалізовано назви груп, щоб зайві пробіли не ховали заняття;
- записи зі старим/невідомим `pairId` більше не губляться;
- заняття без номера пари, але з часом, показуються окремим рядком «За часом»;
- записи без номера пари і без часу показуються як «Без номера пари»;
- зверху видно:
  - загальну кількість занять групи у базі;
  - кількість подій на відкритому тижні;
- нижче календаря є список **Найближчі заняття групи**, який показує заняття незалежно від того, який тиждень зараз відкритий;
- клік по заняттю у списку переводить календар на потрібний тиждень.

Це дозволяє одразу відрізнити:
- «заняття є в базі, але вони на іншому тижні»;
- «занять для цієї групи справді немає».
