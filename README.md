# РЕМС-РОЗКЛАД v1.0.7

Виправлено кнопку **«Розставити навантаження»**.

Причина була конкретною: при відкритті нового календарного планувальника
код звертався до відсутньої функції `weekdayNameForDate`, через що JavaScript
зупиняв відкриття модального вікна.

Зміни:
- додано відсутню функцію назви дня тижня;
- кнопка тепер відкриває календар постановки навантаження;
- додано захисну обгортку: якщо в майбутньому всередині планувальника виникне
  інша помилка, система покаже її текст, а не просто виглядатиме як «неактивна кнопка».

На GitHub достатньо замінити:
- `index.html`
- `app.js`

`styles.css`, `cloud.js`, `data.js`, Firebase і Firestore Rules не змінювалися.
