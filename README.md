# РЕМС-РОЗКЛАД v1.0.15 — виправлено режим адміністратора

Виправлено ситуацію, коли адміністратор після відкриття/оновлення сторінки «Розклад викладача» бачив повідомлення «Акаунт ще не прив’язаний до викладача».

## Тепер

### Адміністратор
- не потребує жодної прив’язки до викладача;
- відкриває розклад будь-якого викладача через «Викладачі → Розклад»;
- вибраний викладач запам’ятовується в межах вкладки браузера;
- після оновлення сторінки залишається розклад того самого викладача;
- якщо вибраного викладача немає/видалено, система автоматично повертає у «Викладачі»;
- повідомлення про «не прив’язаний акаунт» адміністратору більше не показується.

### Роль «Викладач»
- як і раніше, бачить тільки «Мій розклад»;
- лише для цієї ролі потрібна прив’язка акаунта до конкретного профілю викладача;
- якщо прив’язки немає, показується коректне повідомлення «Зверніться до адміністратора».

### Під час завантаження Firebase
До моменту визначення ролі показується нейтральне «Завантаження доступу…», а не помилкове повідомлення про прив’язку.
