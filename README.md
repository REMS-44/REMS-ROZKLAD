# РЕМС-РОЗКЛАД v1.0.14 — зручний календар постановки розкладу

Перероблено саме вікно **«Розставити навантаження»**.

## Що прибрано

- горизонтальну прокрутку календаря;
- окрему вертикальну прокрутку таблиці праворуч;
- горизонтальну прокрутку форми додавання пар;
- велику таблицю «викладач / група», у якій частина пар ховалася нижче;
- автоматичний порожній рядок заняття після вибору дати.

Тепер є фактично одна основна прокрутка — самого модального вікна.

## Календар

Календар зліва повністю вміщується по ширині.

У клітинці дня показуються тільки короткі індикатори:
- скільки вже стоїть занять цієї дисципліни;
- скільки інших занять має викладач;
- скільки інших занять має група;
- або «вільний день».

Повна інформація відкривається праворуч після кліку на дату.

## Робоча картка дня

Праворуч завжди видно всі 7 пар без внутрішнього скролу.

Кожна пара окремою карткою показує:
- № пари та час;
- що в цей момент має викладач;
- що в цей момент має група;
- якщо обидва вільні — скільки кафедральних аудиторій вільно.

Якщо пара вільна, прямо в ній є кнопка **«+ Додати»**.

## Додавання заняття

Натискання «+ Додати» біля конкретної пари:
- одразу додає саме цю пару в форму;
- залишається вибрати вид заняття та аудиторію.

Можна вибрати кілька різних вільних пар одного дня й зберегти їх разом.

Форма тепер компактна:
- вид заняття;
- пара;
- аудиторія;
- кількість годин, що спишеться;
- видалення рядка.

Без руху вправо-вліво.
