# РЕМС-РОЗКЛАД v1.0.23

## 1. Серії більше не показують усе одразу

У кафедральних і готових парах логіка однакова.

### Крок 1
- Одна дата
- Серія дат

### Крок 2 — тільки якщо вибрана «Серія дат»
- Конкретні дати
- За правилом

Поки не вибраний другий крок, жодної форми немає.

### Крок 3
Відкривається тільки обрана форма:
- або вставка конкретних дат;
- або генератор щотижня / через тиждень.

### Крок 4
Масові поля, список дат і кнопка збереження серії
з'являються ТІЛЬКИ після того, як уже створена хоча б одна дата.

## 2. Окрема «Доступність» викладача

У списку викладачів кафедри є окрема кнопка:
**Доступність**

Вона відкриває тільки правила розкладу викладача:

### Не можна ставити
- день тижня;
- конкретна дата;
- період дат;
- початок / кінець часу.

### Бажано ставити
Ті самі типи правил, але як бажаний час.

### Ліміти
- максимум пар на день;
- максимум пар підряд.

На картці викладача показується короткий підсумок цих правил.

## 3. Планувальник реально використовує доступність

У списку пар:
- недоступна пара відключається;
- бажаний час позначається як «бажано»;
- якщо на цю дату є бажані години, але пара поза ними — «поза бажаним».

У серії кожен рядок одразу показує:
- викладач зайнятий;
- група зайнята;
- пара недоступна;
- перевищення максимуму пар на день;
- перевищення максимуму пар підряд;
- бажаний час;
- поза бажаним часом.

## 4. Максимум пар підряд

Раніше поле зберігалося, але не перевірялося повноцінно.
Тепер воно реально входить у перевірку при постановці розкладу.
