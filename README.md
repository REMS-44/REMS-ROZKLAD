# РЕМС-РОЗКЛАД v1.0.24 — «Навантаження» за групами

Перебудовано сторінку «Навантаження», щоб вона не перетворювалась
на нескінченний список після додавання планів усіх курсів.

## Верх сторінки — групи

Активовані дисципліни автоматично збираються за групами.

Групи візуально розкладені по курсах:
- 1 курс;
- 2 курс;
- 3 курс;
- 4 курс.

Кожна група — окрема активна картка.

На картці видно:
- код групи;
- курс;
- кількість студентів;
- скільки активних дисциплін;
- скільки вже готово;
- скільки потребують уваги.

Якщо все розподілено — зелена позначка.
Якщо є незавершені дисципліни — видно їх кількість.

## Одночасно відкрита лише одна група

Натискаєш, наприклад, «РЕМС-44» —
нижче показуються ТІЛЬКИ дисципліни РЕМС-44.

Інші групи залишаються зверху як вкладки-картки.

Вибрана група запам'ятовується в межах сесії браузера.

## Фільтри всередині групи

- Усі;
- Потребують уваги;
- Розподілено.

Коли для групи активовані дисципліни різних семестрів,
автоматично з'являються ще вкладки:
- Усі семестри;
- 5 семестр;
- 6 семестр;
- тощо.

## Дисципліни

Замість великої загальної таблиці кожна дисципліна має компактний рядок:

- назва;
- семестр;
- форма контролю;
- викладачі;
- статус розподілу;
- прогрес аудиторних годин;
- залишок;
- «Розподілити години» / «Переглянути розподіл».

Колір дисципліни використовує ту саму стабільну логіку
«дисципліна + група», що й календарі.
