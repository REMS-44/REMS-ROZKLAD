# РЕМС-РОЗКЛАД v0.9.5 — користувачі та ролі

## Нове
- Адміністраторська вкладка **Користувачі**.
- Створення окремого Firebase Authentication акаунта прямо з РЕМС-Розкладу.
- Створення відбувається через окремий Firebase app instance, тому адміністратора не викидає з його сесії.
- Після створення можна автоматично надіслати користувачу email для встановлення власного пароля.
- Ролі: Адміністратор, Диспетчер, Викладач, Перегляд.
- Зміна ролі в один клік.
- Блокування / відновлення доступу в реальному часі.
- Надсилання листа для зміни пароля.
- Редагування ПІБ.
- Адміністратор не може випадково заблокувати власний акаунт або зняти із себе роль адміністратора через інтерфейс.

## Важлива зміна правил Firestore
Після першого bootstrap новий Firebase Authentication акаунт сам по собі більше НЕ отримує профіль viewer.
Профіль доступу може створити лише адміністратор. Це означає, що сторонній Auth-акаунт не зможе читати спільну базу.

Перед використанням вкладки «Користувачі» опублікуйте файл `firestore.rules` у:
Firebase → Firestore → Правила.
