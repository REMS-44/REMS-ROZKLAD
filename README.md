# РЕМС-РОЗКЛАД v1.0.13 — вікна в індивідуальному розкладі викладача

Індивідуальний місячний розклад викладача тепер має ту саму структуру,
що й розклад групи.

У кожному дні показуються всі пари з розкладу дзвінків.

Якщо пара зайнята:
- номер пари;
- група;
- дисципліна;
- вид заняття;
- аудиторія.

Якщо пара вільна:
- у відповідній смузі прямо написано **«вікно»**.

Таким чином викладач одразу бачить не тільки свої заняття, а й проміжки між ними.

Кольори залишаються стабільними за правилом:
**дисципліна + група**.

Тому та сама пара має однаковий колір у:
- розкладі групи;
- індивідуальному розкладі викладача;
- сітці аудиторій;
- календарі постановки розкладу.

На GitHub замінити:
- `index.html`
- `app.js`
- `styles.css`

`cloud.js`, `data.js`, Firebase і Firestore Rules не змінювалися.
