# РЕМС-РОЗКЛАД v1.2.1 — центр налаштувань

## Налаштування як головний каталог

На головній сторінці налаштувань тепер є три великі картки:
- Види занять і правила годин
- Користувачі та доступ
- Розклад дзвінків

Розклад дзвінків більше не розгорнутий унизу довгої сторінки.

## Окремі робочі екрани

Кожна з трьох карток відкриває свій екран.

На кожному екрані зверху є велика кнопка:
**← Повернутися до налаштувань**

Тому більше не потрібно повторно шукати «Налаштування» у лівому меню.

## Розклад дзвінків

Тепер це повноцінна окрема сторінка:
- кількість пар;
- редагування часу;
- додавання нової пари;
- збереження;
- повернення в налаштування.

## Користувачі

Сторінка користувачів також зберігає верхню панель повернення,
навіть коли Firebase повторно оновлює список користувачів.
