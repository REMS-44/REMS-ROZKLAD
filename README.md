# РЕМС-РОЗКЛАД v1.0.29

Праву частину «Розставити навантаження» спрощено.

Тепер там тільки три великі кнопки:

- Доступність викладача
- Одна дата
- Серія дат

Кожна відкриває окреме спливаюче вікно поверх календаря.

Після збереження popup закривається, а основний планувальник
залишається на тій самій дисципліні, викладачі, місяці й даті.

## Доступність
Окреме popup-вікно:
- Не можна ставити
- Бажано ставити
- максимум пар на день
- максимум пар підряд

## Одна дата
Окреме popup-вікно для вибраної дати:
- кілька пар одного дня
- вид заняття
- пара
- аудиторія
- охоплення
- примітка

## Серія дат
Окреме широке popup-вікно:
- Конкретні дати
- або За правилом
- масові параметри
- окремі картки дат
