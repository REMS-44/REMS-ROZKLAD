# РЕМС-РОЗКЛАД v1.2.0 — читабельний студійний інтерфейс

Це візуальний прохід по всьому застосунку без зміни логіки та даних.

Основні принципи:
- важлива інформація стала значно більшою;
- прибрано мікроскопічні службові шрифти;
- зменшено беззмістовну порожнечу;
- картки та таблиці стали щільнішими;
- збережено повітря між логічними блоками;
- основний фіолетовий стиль став виразнішим.

Особливо перероблено:
- планувальник розкладу;
- ПІБ викладача у планувальнику;
- картки груп;
- перемикачі груп;
- місяці;
- календарі;
- навантаження;
- картки дисциплін і викладачів;
- таблиці;
- popup-вікна;
- доступність викладача.

У планувальнику тепер окремими великими блоками видно:
- дисципліну;
- викладача;
- групу;
- семестр;
- залишок годин.

На GitHub замінити:
- index.html
- app.js
- styles.css

data.js і cloud.js не змінювалися.
