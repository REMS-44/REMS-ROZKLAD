# РЕМС-РОЗКЛАД v1.0.11 — готові пари інших кафедр

Додано другий маршрут внесення занять.

## Кафедральні заняття
Навчальний план → активація → Навантаження → розподіл → Складання розкладу.

## Готові заняття інших кафедр
Складання розкладу → **+ Внести готові пари**.

Їх не потрібно активувати та не потрібно додавати в кафедральне навантаження.

### Дисципліна
Можна вибрати дисципліну прямо з навчального плану, навіть якщо вона не активована.
Не кафедральні / загальноосвітні дисципліни показуються першими.

Також можна вибрати «Інша дисципліна» й ввести назву вручну.

### Викладач
ПІБ можна:
- вибрати/ввести з наявного довідника;
- ввести вручну для зовнішнього викладача.

Якщо ПІБ точно збігається з викладачем у довіднику, запис отримує teacherId
і автоматично з’являється в індивідуальному розкладі цього викладача.

### Аудиторія
Поле вільне, але має підказки з довідника.
Можна ввести 324, 415, онлайн або будь-яке інше значення.

Чужа аудиторія не додається автоматично до кафедральної сітки.
Якщо використана кафедральна аудиторія, її зайнятість одразу видно в сітці.

### Масове внесення
Можна:
- додавати рядки вручну;
- вставити список дат: `03.09, 10.09, 17.09, 24.09`;
- застосувати один вид заняття, одну пару або одну аудиторію до всіх рядків;
- після цього відредагувати окремі рядки.

Кожен рядок містить:
- дату;
- вид заняття;
- пару;
- аудиторію.

### Облік
Такі записи записуються в той самий `schedule`, але мають `workloadHours = 0`.
Тому вони:
- є в готовому розкладі групи;
- є в списку виставлених занять;
- блокують групу й аудиторію;
- потрапляють у розклад викладача, якщо є teacherId;
- не змінюють кафедральне навантаження.
