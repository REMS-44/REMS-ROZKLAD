# РЕМС-РОЗКЛАД v1.9.0 — Word-експорт по курсу

## Нове

У вкладці **Розклад** з’явилася кнопка **Word по курсу**.

Вона формує `.docx` прямо в браузері, без сервера і без Firebase-записів.

### Логіка
- вибір курсу видимими кнопками;
- вибір I / II семестру;
- у файл потрапляють **усі групи нашої бази цього курсу**;
- виключаються індивідуальні заняття та консультації;
- включаються і кафедральні, і готові пари інших кафедр — усе, що реально стоїть у груповому розкладі;
- потокова пара об’єднується по колонках груп;
- однакові заняття з різними датами групуються в один блок: дисципліна → вид + дати → викладач + аудиторія;
- документ розбито за днями тижня;
- Понеділок–П’ятниця завжди присутні; Субота додається, якщо є заняття.

### Формат під надісланий факультетський зразок
- A4 landscape;
- Times New Roman 12 pt;
- `Пара` — 788 twips;
- `Тривалість` — 1720 twips;
- **кожна групова колонка — 4445 twips**, як у надісланому зразку;
- заголовок групи + кількість студентів;
- чорна сітка таблиці;
- дисципліна жирним;
- вид заняття + дати курсивом;
- викладач + аудиторія жирним.

Спеціально НЕ додаються факультетські блоки `ЗАТВЕРДЖУЮ` та підписи — це фрагмент нашої спеціальності для подальшого вставлення в загальний розклад.

# v1.9.1 — Розклад по днях груп

Нова вкладка **«По днях груп»**: курс → група → семестр → день тижня. Рядки — 1–7 пари, колонки — всі дати обраного дня у семестрі. Заповнені клітинки показують дисципліну, викладача, аудиторію та вид заняття; порожні мають кнопку **+ Вільно**.

Клік по порожній клітинці вже передає дату, групу та номер пари і пропонує: кафедральну пару або готову пару іншої кафедри.

На GitHub замінити: index.html, app.js, styles.css.
