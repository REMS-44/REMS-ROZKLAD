# РЕМС-РОЗКЛАД v1.0.28 — групи кнопками

Там, де група використовується як навігація або фільтр,
випадаючі списки замінено на відкритий ряд кнопок.

## Розклад групи
Замість select видно всі групи одразу.

Кнопка показує:
- шифр групи;
- курс;
- кількість занять у базі.

Натискання одразу перемикає календар.

## Складання розкладу
Групи також показуються відкритими кнопками.

На кнопці:
- шифр;
- курс;
- кількість розподілених позицій навантаження.

Групи без розподіленого навантаження теж видно,
але мають позначку «—».

## Журнал занять
Фільтр за групою тепер теж кнопками:
- Усі групи;
- кожна група окремо.

На кнопках є кількість записів.

## Групи і студенти
Фільтр списку студентів:
- Усі групи;
- кнопки кожної групи;
- кількість студентів на кнопці.

## Де select залишився
Випадаючий список залишено у формах створення/редагування:
- додати студента;
- бронювання аудиторії;
- внести готову пару;
- редагувати заняття;
- інші щільні форми.

Там група є полем даних, а не навігацією, тому ряд усіх груп
зайняв би занадто багато місця.
