# РЕМС-РОЗКЛАД v1.0.27

## Дати серії
Кожна дата тепер показується компактною карткою у два рядки.

Перший рядок:
- включити / виключити;
- дата;
- статус;
- видалення.

Другий рядок:
- вид заняття;
- пара;
- аудиторія.

Горизонтальний скрол у списку дат прибрано.

## Доступність викладача
У самому планувальнику тепер велика вкладка
**«Доступність викладача»**.

Натискаєш її — прямо тут відкривається редактор:
- Не можна ставити;
- Бажано ставити;
- максимум пар на день;
- максимум пар підряд.

## Після збереження
«Зберегти доступність» більше не закриває планувальник
і не перекидає на сторінку «Навантаження».

Зберігаються:
- відкрита дисципліна;
- викладач;
- дата;
- місяць;
- уже створені, але ще не збережені рядки серії.

Перевірки доступності для рядків оновлюються одразу.
