# РЕМС-РОЗКЛАД v1.0.20

## 1. «Розставити навантаження»

Після вибору дати більше НЕ відкривається автоматично форма додавання.

Спочатку видно тільки дві кнопки:
- **Одна дата**
- **Серією за правилом**

Поки режим не вибрано — нижче немає зайвих полів.

Натискання «+ Додати» безпосередньо біля вільної пари автоматично
відкриває режим «Одна дата» і додає саме цю пару.

## 2. «Внести готові пари»

Для занять інших кафедр / дисциплін без кафедрального навантаження
додано той самий принцип.

Після загальних полів (група, дисципліна, викладач, охоплення)
видно тільки:

- **Одна дата**
- **Серія дат**

### Одна дата
Звичайне внесення:
- дата;
- вид;
- пара;
- аудиторія.

### Серія дат

Є ДВА способи створити серію.

#### А. Конкретні дати
Можна вставити:
`03.09, 10.09, 17.09, 24.09`

#### Б. За правилом
Можна задати:
- щотижня / через тиждень;
- день тижня;
- період «від / до».

Після генерації кожна дата стає окремим рядком.

Для всієї серії можна одним разом задати:
- вид заняття;
- пару;
- аудиторію.

Після цього БУДЬ-ЯКУ конкретну дату можна змінити окремо:
- інший вид;
- інша пара;
- інша аудиторія;
- додати ще одну дату вручну.

Це зручно для політології, філософії та інших готових / потокових пар,
які приходять уже сформованими й не входять у навантаження кафедри.
