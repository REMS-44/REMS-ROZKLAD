# РЕМС-РОЗКЛАД v1.0.4 — наскрізний робочий процес

Ця версія виправляє саме логіку зв'язків між навчальним планом, навантаженням і всіма видами розкладів.

## Єдине джерело даних

Правильний ланцюжок тепер такий:

1. **Навчальний план**
   - дисципліна і її години беруться з робочого плану;
   - кнопка «У навантаження» активує дисципліну для конкретної групи.

2. **Навантаження**
   - активована дисципліна з'являється у вкладці «Навантаження»;
   - викладачі додаються **по одному**;
   - можна спочатку розподілити частину годин одному викладачу, зберегти, а пізніше додати другого/третього;
   - уже внесений розподіл не стирається при додаванні нового викладача;
   - по кожному виду занять видно: план / розподілено / залишилось;
   - не можна розподілити більше годин, ніж є в плані;
   - не можна зменшити навантаження викладача нижче кількості годин, які вже виставлені йому в розклад;
   - не можна прибрати викладача з дисципліни, якщо для нього вже є заняття в розкладі.

3. **Складання розкладу**
   - сюди потрапляють тільки **аудиторні пари** (лекція, семінар, практичне, лабораторне), які реально розподілені між викладачами;
   - для кожного викладача і виду заняття видно: план / виставлено / залишок;
   - не можна виставити більше годин, ніж було розподілено цьому викладачу;
   - кожне заняття записується один раз у `schedule` з обов'язковими зв'язками: група, дисципліна, викладач, дата, пара, аудиторія.

4. **Автоматичне відображення**
   Один запис заняття автоматично з'являється у:
   - готовому розкладі групи;
   - сітці зайнятості аудиторій;
   - індивідуальному розкладі викладача;
   - списку виставлених занять.

   Ніяких окремих копій розкладу для цих сторінок немає.

## Готовий розклад групи

Виправлено попередню помилку: місячний вигляд потрібен був саме для **готового розкладу групи**.

Тепер:
- зверху вкладки Вересень — Червень;
- вибір групи;
- нижче повний календар вибраного місяця;
- в кожному дні видно пару, дисципліну, викладача й аудиторію;
- на вкладці місяця видно кількість подій.

## Індивідуальний розклад викладача

Також залишається місячним:
- Вересень — Червень;
- усі заняття викладача беруться з того самого `schedule`;
- окремий викладацький акаунт бачить тільки свій календар.

## Сумісність зі старими записами

При збереженні система нормалізує старі записи розкладу:
- відновлює групу через активовану дисципліну;
- відновлює назву дисципліни через `disciplineId`;
- відновлює викладача через `teacherId`;
- синхронізує час із номером пари.

## Перевірка

Версію перевірено локальним браузерним тестом на повному ланцюжку:

**активація з плану → розподіл між двома викладачами → виставляння заняття → готовий розклад групи → індивідуальний розклад викладача → сітка аудиторії.**

Усі п'ять представлень отримали один і той самий запис заняття без помилок JavaScript.
