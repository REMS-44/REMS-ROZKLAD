# РЕМС-РОЗКЛАД v1.9.4.0 — потоки в «Навантаженні»

Потік тепер задається не під час вибору конкретної дати, а під час розподілу навантаження — окремо для кожного виду занять.

Приклад:
- Лекція → **ПОТІК · РЕМС-44 + РЕМС-34**
- Практичне → **ОКРЕМО · РЕМС-44**
- Лабораторне → **ОКРЕМО · РЕМС-44**

## Як налаштувати
1. «Навантаження» → дисципліна.
2. Розподілити години викладачу.
3. Під кожним аудиторним видом є кнопка «Окремо · група».
4. Натиснути й додати інші групи до потоку.

Друга група одразу отримує той самий вид і той самий обсяг годин у цього викладача.

## Навантаження викладача
Якщо 10 год лекцій РЕМС-44 і 10 год лекцій РЕМС-34 читаються одним потоком, у загальному навантаженні викладача це рахується як **10 фактичних годин**, а не 20. У плані кожної групи свої 10 год залишаються забезпеченими.

## Складання розкладу
Групи підставляються автоматично за видом заняття. Тому одна серія може містити:
- потокові лекції для двох груп;
- окремі практичні для однієї групи.

## Word
Word-експорт бере групи з фактичної пари, тому потокова лекція автоматично відображається в обох групах.
