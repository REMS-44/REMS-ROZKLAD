Саме ця функція формує дані для правої робочої картки вибраного дня:
- заняття цієї дисципліни;
- усі заняття викладача цього дня;
- усі заняття групи цього дня.

Через її відсутність кнопка вже відкривала планувальник, але рендер
зупинявся при побудові панелі дня.

Додатково виконано автоматичну перевірку всіх функцій із префіксом `planner`:
у коді більше немає викликів `planner...`, для яких відсутнє визначення функції.
