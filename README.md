# РЕМС-РОЗКЛАД v1.4.0

## 1. Виправлено І / ІІ половину пари

Причина помилкового конфлікту знайдена:
після синхронізації індивідуальна половина пари могла
перетворюватися назад на повну пару.

Тепер:
- І половина займає тільки І половину;
- ІІ половина тієї ж пари залишається доступною;
- уже збережені спеціальні записи автоматично відновлюють
  правильний час за полем specialHalf.

## 2. Індивідуальне навантаження = години НА СТУДЕНТА

Якщо в навчальному плані стоїть:
2 години індивідуальних

і у групі 17 студентів, повний обсяг дисципліни:
2 × 17 = 34 години.

Викладачу не видається вся група автоматично.
У «Навантаженні» для індивідуального виду з'являється:
**Обрати студентів**

Наприклад:
- Фішер — 5 студентів → 2 × 5 = 10 год;
- Крикуненко — 12 студентів → 2 × 12 = 24 год.

Один студент не може бути закріплений за двома викладачами
в межах одного індивідуального виду цієї дисципліни.

У спеціальному розкладі викладач бачить тільки своїх студентів.
Для кожного видно прогрес:
0 / 2, 1 / 2, 2 / 2 год.

## 3. «Готовий окремий розклад» тепер ПО ДИСЦИПЛІНІ

Режисура, драматургія та інші дисципліни більше не змішуються.

Порядок:
1. режим — індивідуальні / бакалаври / магістри;
2. група;
3. дисципліна;
4. місяць;
5. готовий розклад тільки цієї дисципліни.

Наприклад:
- «Режисура естради і шоу» — свій окремий розклад;
- «Драматургія шоу» — свій окремий розклад.
