# РЕМС-РОЗКЛАД v1.0.25

Ця версія виправляє ситуацію, коли після оновлення сторінка
«Навантаження» могла виглядати як стара версія.

## Головна зміна

Старої плоскої таблиці всіх дисциплін на сторінці «Навантаження»
більше немає.

Інтерфейс побудований у 2 кроки:

### КРОК 1 — Оберіть групу
Групи показуються великими активними картками за курсами.

Наприклад:

1 курс
- РЕМС-46
- РЕМС-76

2 курс
- РЕМС-45

3 курс
- РЕМС-44
- РЕМС-34

4 курс
- РЕМС-43

На картці групи:
- кількість дисциплін;
- скільки розподілено;
- скільки потребують уваги;
- кількість студентів.

### КРОК 2 — Дисципліни вибраної групи
Нижче показуються ТІЛЬКИ дисципліни активної групи.

Є фільтри:
- Усі;
- Потребують уваги;
- Розподілено;
- семестр, якщо їх кілька.

## Важливе технічне виправлення

До файлів додано номер версії:

- `styles.css?v=1.0.25`
- `app.js?v=1.0.25`
- `cloud.js?v=1.0.19r2`

Це змушує браузер та GitHub Pages завантажити нові файли,
а не використовувати стару закешовану копію.

## Оновлення GitHub

Цього разу замінити:
- `index.html`
- `app.js`
- `styles.css`

Сам `cloud.js` функціонально не змінювався від v1.0.19,

з однієї збірки.
