# РЕМС-РОЗКЛАД v1.0.26

Ця версія виправляє дві конкретні помилки попередніх збірок.

## 1. Чому «Конкретні дати» і «За правилом» показувалися одночасно

У HTML блоки мали клас `hidden`, але в CSS не було універсального правила:

`.hidden { display: none; }`

Тому браузер показував обидві форми одночасно.

Тепер додано:
`.hidden { display:none!important; }`

Отже логіка справді покрокова:

### Крок 1
- Одна дата
- Серія дат

### Крок 2
Якщо обрана «Серія дат»:
- Конкретні дати
- За правилом

### Крок 3
Відкривається ТІЛЬКИ обраний спосіб.

### Крок 4
Масові поля та список серії з'являються тільки після створення дат.

Це діє і для кафедральних, і для готових некафедральних пар.

## 2. Доступність викладача тепер видно В САМОМУ планувальнику

У правій робочій колонці над додаванням занять з'явився компактний блок:

**Доступність викладача**

У ньому видно:
- не можна ставити;
- бажано ставити;
- максимум пар на день;
- максимум пар підряд;
- статус для вибраної дати.

Наприклад:
- «Цього дня викладач недоступний»
- «Є недоступні години»
- «Є бажані години цього дня»
- «Цей день не входить до бажаних»
- «Можна ставити»

Є кнопка **«Змінити»**, яка одразу відкриває налаштування доступності цього викладача.

## 3. Доступність видно і в календарі

У клітинці дня може бути маленька позначка:
- `бажано`
- `викл. не може`
- `є обмеження`
- `поза бажаним`

Тому ще до відкриття дати видно, наскільки вона підходить викладачу.

## 4. При виборі пари

У випадаючому списку пари:
- жорстко недоступна пара має `НЕ МОЖНА` і відключена;
- бажаний час має `БАЖАНО`;
- інший час — `поза бажаним часом`.
