# РЕМС-РОЗКЛАД v1.0 — порядок аудиторій + індивідуальний розклад викладача

## 1. Порядок аудиторій у сітці
У «Аудиторії → Довідник аудиторій»:
- з’явилася колонка **Порядок**;
- кнопки **↑ / ↓** змінюють порядок аудиторій;
- цей порядок автоматично використовується як порядок колонок у «Сітці зайнятості»;
- у формі редагування аудиторії можна ввести **Позицію в сітці**;
- приховані аудиторії не займають позицію в сітці.

## 2. Індивідуальний розклад викладача
У картці кожного кафедрального викладача є кнопка **Розклад**.

Адміністратор може відкрити та перевірити індивідуальний календар будь-якого викладача.

Для ролі **Викладач**:
- акаунт прив’язується до конкретного викладача;
- після входу доступна тільки сторінка **«Мій розклад»**;
- видно тижневий календар: дата, пара, група, дисципліна/подія, аудиторія;
- зміни загального розкладу підтягуються автоматично через Firestore;
- є перехід по тижнях та до конкретної дати;
- є кнопка виходу.

## 3. Користувачі
«Налаштування → Користувачі та доступ»:
- для ролі «Викладач» додано поле **Прив’язка до викладача**;
- без прив’язки викладацький акаунт не отримує індивідуальний розклад;
- прив’язку можна змінити пізніше.

## 4. Безпека Firestore
Правила v1.0 змінено:
- роль «Викладач» не читає навчальні плани, студентів, викладачів, навантаження та інші кафедральні колекції;
- вона може читати тільки `settings` (навчальний період/дзвінки);
- у `schedule` і `roomBookings` читаються тільки документи, у яких `teacherId` збігається з `teacherId` профілю користувача.
