# РЕМС-РОЗКЛАД 2.0.47

Вебсистема факультетського розкладу, навчальних планів, навантаження, студентів, викладачів та індивідуальних занять.

## Оновлення на GitHub Pages

Завантажте всі файли з цієї папки в корінь репозиторію зі збереженням назв. Головна сторінка — `index.html`.

- `data.js` — початкові дані, навчальні плани, групи та студенти;
- `master-schedules.js` — затверджені розклади МСМ-25 і МСМ-26;
- `app.js` — логіка та інтерфейс;
- `cloud.js`, `firebase-config.js`, `firestore.rules` — Firebase;
- `word-export.js` — експорт у Word;
- `styles.css` — оформлення;
- `HISTORY.md` — стислий перелік важливих змін.
