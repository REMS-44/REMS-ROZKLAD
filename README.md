# РЕМС-РОЗКЛАД v1.4.1 — закріплення студентів за викладачем

## Правильний етап

Конкретні студенти закріплюються за викладачем на етапі:
**Навантаження → дисципліна → викладач → Індивідуальне → Закріпити студентів**

Це НЕ робиться під час вибору дати.

## Старі дані

Раніше система могла побачити одного студента в уже створеному
індивідуальному занятті й помилково вважати його всім списком.

Тепер:
- старі записи — лише підказка;
- студенти з уже створених занять попередньо відмічаються;
- адміністратор все одно бачить всю групу;
- потрібно один раз підтвердити повний список закріплених студентів.

Наприклад:
2 год на студента,
старе навантаження викладача 10 год
→ орієнтир 5 студентів.

Якщо у старому розкладі вже є Баленко,
вона буде попередньо відмічена,
але система покаже всю групу й запропонує вибрати решту.

## Індивідуальний розклад

Після збереження закріплення:
- у викладача завжди видно ВСІХ його студентів;
- Баленко 1/2;
- інший студент 0/2;
- ще інший 0/2;
- студент із 2/2 залишається видимим як «ГОТОВО», але недоступний для нового запису.

На сторінці «Індивідуальні» якщо студентів ще не закріплено,
кнопка «Додати студенту» замінюється на:
**Закріпити студентів**

Її можна натиснути прямо там — не треба шукати дисципліну вручну.
