# РЕМС-РОЗКЛАД v1.0.21

Перероблено календар усередині «Розставити навантаження».

## Клітинки місяця

Замість абстрактних написів:
- «1 своя»
- «група 1»
- «викл. 2»

тепер у клітинці видно конкретну інформацію про пару.

Наприклад:
- `1п · Лекція · 230`
- `3п · викл. · РЕМС-44`
- `5п · група · Кучер Д.Ю.`

Якщо подій багато, показуються перші три й напис `+N ще`.

## Після кліку по даті

ПОВНИЙ розклад вибраного дня тепер відкривається
**під календарем зліва**, а не ховається в правій колонці.

Для всіх 7 пар видно:

| Пара | Група | Викладач |
|------|-------|-----------|

У кожній парі:
- заняття групи або «вільно»;
- заняття викладача або «вільно»;
- дисципліна;
- ПІБ / група;
- аудиторія;
- вид заняття.

## Права колонка

Праву колонку залишено саме для роботи:
- «Одна дата»;
- «Серією за правилом»;
- додавання нових занять.

Тобто:
- **зліва дивимося, що вже стоїть**;
- **справа додаємо нове**.
