# РЕМС-РОЗКЛАД v1.4.2 — редагування готових індивідуальних записів

## Готовий окремий розклад тепер активний

Натисни на будь-який рядок індивідуального заняття / консультації.

Відкривається редактор уже з поточними даними:
- студент;
- дата;
- номер пари;
- І або ІІ половина;
- аудиторія;
- примітка.

## Під час редагування

Система:
- не рахує цей самий запис конфліктом;
- не блокує його власну аудиторію;
- не списує його годину вдруге;
- не вважає поточного студента таким, що вже вичерпав годину саме через цей редагований запис.

Після зміни знову перевіряються:
- студент;
- викладач;
- аудиторія;
- групова пара;
- обмеження викладача.

## Вигляд

На рядку є невелика підказка:
**Редагувати ✎**

Хрестик праворуч лишився окремою кнопкою видалення.
