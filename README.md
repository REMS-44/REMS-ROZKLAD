# РЕМС-РОЗКЛАД v0.9.8

## Що змінило

- Після оновлення сторінки система **залишається у тій самій вкладці**.
- Поточна вкладка також записується в адресу після `#`, тому браузер більше не повертає на «Головну».
- При вході у **«Розклад»** автоматично відкривається тиждень, у якому знаходиться актуальний навчальний день.
- При вході у **«Зайнятість аудиторій»** автоматично відкривається актуальний навчальний день і відповідний місяць.
- Якщо сьогодні липень або серпень, дата автоматично обмежується найближчою межею активного навчального року, бо липень і серпень у календарях не використовуються.
- У розкладі групи запам’ятовується остання вибрана група.
- В «Зайнятості аудиторій» активна дата автоматично прокручується в центр смуги місяця.
- Для дат використовується локальна дата комп’ютера, а не UTC, щоб біля опівночі календар не перескакував на сусідній день.
