# РЕМС-РОЗКЛАД v1.9.3 — вибіркові дисципліни

## Новий тип аудиторії дисципліни
Кожна кафедральна дисципліна тепер має режим **Вся група** або **Вибрані студенти**. Склад задається один раз у «Навантаженні» через кнопку «Хто слухає дисципліну».

## Приклад
РЕМС-44 — 17 студентів. «Візуальні ефекти» — 7 вибраних студентів, «Моделювання стилю» — інші 10. Їх можна поставити на одну пару, якщо списки студентів не перетинаються, викладачі різні й аудиторії різні.

## Конфлікти
Повна група конфліктує з будь-якою вибірковою дисципліною цієї групи. Дві вибіркові дисципліни конфліктують тільки за спільного студента. Індивідуальне заняття / консультація теж конфліктує з вибірковою дисципліною для того самого студента.

## Потоки
Для однакової дисципліни у двох групах кожна група має власний список вибраних студентів. Під час постановки можна об'єднати ці групи в одну реальну потокову пару.

## «По днях груп»
Якщо на парі стоїть лише частина групи, клітинка показує кнопку **+ Паралельно** і кількість студентів, які ще вільні.

## Word
Вибіркова пара позначається як **Вибіркова група · N студентів**. Паралельні вибіркові дисципліни формуються як окремі блоки у колонці групи.

## Firebase
Для часткових аудиторій додано shared-контроль конкретних студентів. Повногрупові заняття не отримують десятки student-lock записів.
