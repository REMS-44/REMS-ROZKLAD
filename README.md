# РЕМС-РОЗКЛАД v1.0.5

Виправлено ланцюжок:
Навчальний план → Навантаження → розподіл між викладачами → Складання розкладу.

Головне:
- Лекція, Семінар, Практичне і Лабораторне тепер завжди розпізнаються як аудиторні види.
- Прибрано автоматичне приписування всього плану одному викладачу.
- Рахуються тільки явно розподілені години.
- Викладач із 0 годин не показується як такий, що читає дисципліну.
- «Складання розкладу» за замовчуванням відкриває групу, де вже є розподілене аудиторне навантаження.
- Групи з навантаженням стоять першими.
- Картку навантаження викладача спрощено і очищено від зайвої інформації.
- Неаудиторні години не рахуються як години, які треба розставити у звичайному розкладі.
