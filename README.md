# РЕМС-РОЗКЛАД v1.8.0 — Центр резервних копій

## Що додано

У «Налаштуваннях» тепер є один великий блок:
**Резервні копії → Відкрити центр копій**

### 1. Локальні контрольні точки
- зберігаються в IndexedDB браузера;
- не використовують Firebase і не витрачають його квоту;
- система тримає максимум 10 останніх;
- старі видаляються автоматично;
- під час активної роботи автоматична точка створюється приблизно раз на 45–60 секунд;
- можна створити точку вручну.

### 2. Безпечне відновлення
Для кожної точки видно:
- дату й час;
- тип (авто / вручну / страхувальна);
- кількість груп, студентів, викладачів, дисциплін і записів;
- приблизний розмір.

Кнопка «Відновити»:
- попереджає, що відновлення адміністратора піде у Firebase;
- перед відновленням автоматично створює ще одну страхувальну точку.

### 3. Повний JSON
«Завантажити повний JSON» створює зовнішній файл:
- групи;
- студенти;
- викладачі;
- навчальні плани;
- дисципліни / навантаження;
- розклад;
- індивідуальні й консультації;
- аудиторії;
- налаштування.

Файл має службову оболонку REMS-ROZKLAD-BACKUP v1,
але імпорт також приймає старі JSON-копії без оболонки.

### 4. Безпечний імпорт
Перед імпортом:
- показується короткий склад копії;
- система просить підтвердження;
- поточна база автоматично зберігається як страхувальна точка.

### 5. Безпечне скидання
Перед «Скинути дані» теж автоматично створюється страхувальна точка.

## Важливо

Локальні контрольні точки живуть лише в цьому конкретному браузері.
Якщо очистити дані браузера або втратити комп’ютер — вони теж зникнуть.

Тому періодично обов’язково:
**Резервні копії → Завантажити повний JSON**

JSON — це незалежна від Firebase і браузера зовнішня копія.
