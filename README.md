# РЕМС-РОЗКЛАД v1.1.1

## Складання розкладу: дисципліна більше не дублюється

Раніше:
- одна дисципліна повторювалася окремим рядком для кожного викладача.

Тепер:
- одна дисципліна = один великий блок;
- усередині — окремі картки викладачів.

На рівні дисципліни видно:
- назву;
- групу;
- семестр;
- форму контролю;
- кількість викладачів;
- загальний прогрес;
- загальний залишок годин.

Усередині кожного викладача:
- його види занять;
- заплановано / виставлено;
- залишок;
- кнопка «Розставити» або «Переглянути календар».

Це особливо зручно, коли одну дисципліну ведуть 2–3 викладачі.
