# РЕМС-РОЗКЛАД v1.6.0

## Що виправлено

### 1. «Складання розкладу» — компактно
На широкому екрані дисципліни йдуть по дві в ряд. Одна дисципліна має одну кольорову сім’ю; 2–3 викладачі всередині — лише різні відтінки.

### 2. Готові / загальноосвітні дисципліни не зникають
Блок «Інші кафедри / готовий розклад» у «Навантаженні» тепер формується не тільки з уже внесених пар, а й безпосередньо з навчального плану. Тому політологія, філософія тощо видно навіть при 0 внесених пар.

Поля sourceCurriculumId/sourceComponentId/sourceSemester/sourcePlanRef більше не втрачаються при Firebase-міграції. Готова пара не може випадково перетворитися на кафедральну дисципліну лише через однакову назву.

### 3. Редагування готових пар
У картці загальноосвітньої дисципліни є «Відкрити дисципліну / Редагувати пари». Всі внесені дати можна редагувати або видаляти. У місячному розкладі натискання на готову пару також відкриває правильний редактор готової пари.

### 4. Зовнішні викладачі
ПІБ із готової пари створює/знаходить зовнішнього викладача. Старі готові записи без коректного зв’язку ремонтуються. Статистика викладача читає реальний розклад: дисципліни, групи/потоки, кількість пар і академічних годин.

### 5. Потокові пари — кілька груп разом
У «Внести готові пари» є блок «Хто слухає цю пару». Можна вибрати, наприклад, РЕМС-46 + РЕМС-76. Це один запис, одна аудиторія, один викладач, але пара видима в розкладі обох груп.

Для кафедральних дисциплін у календарному планувальнику є «Групи / потік». Друга група доступна, якщо в ній активована та сама дисципліна (той самий семестр) і відповідний вид годин розподілений тому самому викладачу. Одна потокова пара списує відповідні години в обох дисциплінах і блокує обидві групи в конфліктах/Firebase.
