# РЕМС-РОЗКЛАД v0.7

## Головні зміни

### Навчальний план став повністю редагованим
- можна редагувати реквізити плану, навчальний рік, курс, групи та кількість тижнів;
- можна створювати, перейменовувати і видаляти окремі блоки;
- у кожен блок можна додавати дисципліни;
- у дисципліні можна додавати кілька семестрових рядків;
- редагуються форма контролю, кредити, загальні, аудиторні, лекційні, семінарські, практичні, лабораторні, індивідуальні години, самостійна робота, практика та години на тиждень.

### Автоматична синхронізація
Для дисциплін, уже активованих через «У навантаження», зміна навчального плану автоматично оновлює:
- назву дисципліни;
- семестр і форму контролю;
- усі години;
- картки навантаження викладачів;
- залишки годин у розкладі.

Якщо години вже були розподілені між кількома викладачами, при зміні плану їхній розподіл масштабується пропорційно до нового обсягу. Якщо заняття вже виставлені понад новий обсяг, розклад не видаляється — система покаже перевищення / від’ємний залишок.

### Вкладка «Викладачі» спрощена
У загальному списку видно лише:
- ПІБ;
- штатний / сумісник / погодинник;
- обсяг ставки;
- кнопки «Картка навантаження», «Редагувати», «Видалити».

Повний профіль і деталі навантаження залишаються всередині картки / редагування.

### Важливо
Дисципліни, створені з навчального плану, більше не дозволяють вручну змінювати назву, семестр, контроль і загальні години у вкладці «Дисципліни / навантаження». Це редагується в першоджерелі — навчальному плані. У навантаженні редагуються викладачі та розподіл годин.
