# РЕМС-РОЗКЛАД v0.9.6 — зайнятість аудиторій

Нове:
- окрема вкладка «Зайнятість аудиторій»;
- у довіднику аудиторій є прапорець «Показувати у сітці кафедри»;
- сітка: аудиторії по горизонталі, пари по вертикалі, обрана дата + швидка навігація по місяцю;
- звичайні заняття автоматично займають аудиторію у сітці;
- у вільній клітинці можна створити репетицію, майстер-клас, зустріч, додаткову пару, захід або інше бронювання;
- бронювання може бути невидимим у загальному розкладі групи або, за бажанням, показуватися там;
- бронювання не додає годин у викладацьке навантаження;
- конфлікти аудиторії / групи / викладача перевіряються;
- Firestore синхронізує `roomBookings` у реальному часі; транзакційні locks не дають двом користувачам одночасно зайняти ту саму аудиторію.

Оновити на GitHub: `index.html`, `app.js`, `cloud.js`, `styles.css`, `data.js`.
Також опублікувати новий `firestore.rules` у Firebase → Firestore → Правила.
