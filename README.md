# РЕМС-РОЗКЛАД v1.1.0 · студійний інтерфейс

Великий візуальний редизайн без зміни логіки даних.

## Нова стилістика
- темна творча бічна панель у стилі режисерського пульта;
- виразніша типографіка та ієрархія;
- акцентна лінія / «сценічне світло»;
- новий головний екран із навчальним сезоном;
- нові KPI-картки;
- великі картки груп із чітким курсом і лічильником;
- легкі кольорові акценти курсів;
- оновлені місяці, таблиці, форми, модальні вікна;
- оновлені картки викладачів, планів, навантаження;
- візуально посилені календарі та сітка аудиторій;
- уніфіковані кнопки та стани.

## Групи
Кнопки груп тепер більші й центровані.
Великим видно шифр групи, окремо — курс, у куті — лічильник.
Курси мають дуже легкі різні акценти, без «світлофора».

## Важливо
Функціональну логіку, Firebase, дані, навантаження та розклади не змінювали.
