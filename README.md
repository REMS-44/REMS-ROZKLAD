# РЕМС-РОЗКЛАД v0.4

Основні зміни:
- викладачі поділені на **викладачів кафедри** та **зовнішніх викладачів**;
- зовнішнього викладача можна використовувати в розкладі без кафедральної картки навантаження;
- загальноосвітню / зовнішню дисципліну можна вводити прямо в розкладі, не додаючи її до кафедральних дисциплін;
- для викладача кафедри додані:
  - дата початку роботи;
  - дата завершення роботи / контракту;
  - обсяг ставки;
  - норма навчальних годин на 1 ставку;
  - бажаний і небажаний час як:
    - день тижня;
    - конкретна дата;
    - період дат;
- розклад перевіряє:
  - зайнятість аудиторії;
  - зайнятість групи;
  - накладку викладача;
  - недоступний час;
  - період роботи / контракту;
  - максимум занять на день;
- у дисциплінах додано **розподіл годин між викладачами**;
- картка викладача автоматично показує:
  - перелік дисциплін;
  - групи, курс і контингент;
  - форму контролю;
  - план годин;
  - години, уже виставлені в розклад;
  - залишок;
  - підсумки за видами занять;
  - розподіл виставлених годин за місяцями;
  - цільове навантаження відповідно до ставки та введеної норми на 1 ставку.

Для оновлення GitHub Pages замініть:
`index.html`, `styles.css`, `app.js`, `data.js`.
