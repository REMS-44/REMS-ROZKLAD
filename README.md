# РЕМС-РОЗКЛАД v1.0.18 — серійна постановка занять

У календарі «Розставити навантаження» тепер є два режими:

## Одна дата
Поточний режим:
- вибирається конкретна дата;
- можна поставити одну або кілька пар цього дня.

## Серією за правилом
Для ситуацій, коли дисципліна стоїть регулярно в один день і на одну пару.

Наприклад:
- щопонеділка;
- 2 пара;
- з 07.09 до 21.12.

Пара й правило задаються один раз.

### Після «Побудувати серію»
Система створює список усіх відповідних дат.

Для КОЖНОЇ дати окремо можна:
- включити / пропустити дату;
- вибрати вид заняття:
  - лекція;
  - практичне;
  - лабораторне;
  - інший розподілений вид;
- вибрати аудиторію.

Тому одна й та сама регулярна пара може бути:
- 07.09 — лекція;
- 14.09 — лекція;
- 21.09 — практичне;
- 28.09 — лабораторне.

## Масове заповнення

Є:
- «Вид для всіх»;
- «Аудиторія для всіх»;
- «Автозаповнити за залишком».

«Автозаповнити за залишком» проходить по датах і послідовно розподіляє
доступні види навантаження, не виходячи за залишок годин.

Після автозаповнення будь-яку конкретну дату можна змінити вручну.

## Конфлікти

Якщо на конкретну дату й пару:
- викладач уже зайнятий;
- група вже зайнята,

рядок позначається як конфліктний і не включається в серію.

Аудиторії перевіряються окремо для кожної дати.

## Навантаження

Кожне створене заняття списує години саме з обраного виду навантаження.

Система не дозволяє зберегти серію, якщо:
- не вибраний вид заняття;
- не вибрана аудиторія;
- годин конкретного виду вже недостатньо;
- є конфлікт.

## Інтерфейс

Окрема верхня кнопка «За правилом» зі сторінки складання розкладу прибрана,
бо серійна постановка тепер знаходиться в правильному контексті:
**конкретна дисципліна + конкретний викладач**.
