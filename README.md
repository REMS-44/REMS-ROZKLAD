# REMS-ROZKLAD v2.0.0 — факультетська структура

Додано основу для трьох спеціальностей Факультету театру, кіно та естради.

- Режисура естради і шоу
- Актор театру та кіно
- Режисер театру та кіно

Кафедра режисури та акторської майстерності: групи ТА/ТР і кафедральні аудиторії вже заведені.
Викладачі можуть бути прив’язані до однієї, двох або трьох спеціальностей.
Спільні ресурси зберігаються один раз; робочі екрани фільтруються за обраною спеціальністю.

# РЕМС-РОЗКЛАД v1.9.4.1 — Word з об’єднаними клітинками

## Word: однакова пара кількох груп

Якщо в двох або більше групах збігаються:

- день і номер пари;
- дисципліна;
- вид заняття;
- повний набір дат;
- викладач;
- аудиторія;

Word більше не дублює один і той самий блок у кожній колонці.

Колонки груп об’єднуються горизонтально, і інформація записується один раз.

Це працює як для нових справжніх потокових записів, так і для старих
двох окремих записів груп, якщо їхній розклад фактично повністю однаковий.

## Пара + тривалість

Якщо в межах однієї пари є кілька підрядків, наприклад:

- лекції;
- практичні;
- лабораторні;

клітинки:

- `1`
- `09:00–10:20`

тепер об’єднуються вертикально через усі підрядки цієї пари.

Тобто зліва немає порожніх повторних клітинок.

## Паралельні заняття

Якщо РЕМС-44 і РЕМС-34 одночасно мають різні дисципліни,
вони розміщуються в одному рядку поруч, коли це можливо.

Якщо заняття спільне — групові колонки зливаються в одну.

## Безпека Word

Об’єднання реалізоване стандартними WordprocessingML:
- `w:gridSpan` — горизонтально;
- `w:vMerge` — вертикально.

Після зміни тестовий DOCX:
- перевіряється як ZIP-пакет;
- відкривається python-docx;
- проходить реальний DOCX render pipeline.
