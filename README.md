# РЕМС-РОЗКЛАД v1.0.6

У «Складанні розкладу» один рядок тепер відповідає зв’язці **дисципліна + група + викладач**, а не окремому виду заняття.

Кнопка «Розставити навантаження» відкриває календар місяця. Після вибору дати видно зайнятість викладача і групи по всіх парах, а нижче можна за один раз додати кілька занять різних видів: наприклад лекцію, потім практичне, потім лабораторне.

Для кожного нового заняття вибираються: вид заняття, пара, аудиторія. Стандартна аудиторна пара автоматично списує 2 академічні години.

Зайняті пари викладача/групи та зайняті аудиторії підказуються прямо у формі. Бронювання аудиторії теж блокує її для заняття.

На GitHub замінити: `index.html`, `app.js`, `styles.css`. `cloud.js`, `data.js` і Firestore Rules не змінювалися.
