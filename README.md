# РЕМС-РОЗКЛАД v1.0.9

Виправлено повторну помилку кнопки **«Розставити навантаження»**.

У v1.0.8 кнопка викликала `safeOpenDisciplineTeacherScheduler()`,
але під час переробки календаря сама ця функція випадково була видалена.

Тепер:
- кнопка відкриває календар;
- вибір дати в календарі відкриває/оновлює робочу картку дня;
- якщо всередині планувальника станеться інша помилка, її текст буде показано,
  а не буде враження, що кнопка «неактивна».

На GitHub достатньо замінити:
- `index.html`
- `app.js`

Інші файли не змінювалися.
