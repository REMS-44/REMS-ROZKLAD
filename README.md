# РЕМС-РОЗКЛАД v1.5.0

## Готові пари інших кафедр більше не губляться

У «Навантаженні» вибраної групи тепер є окремий блок:
**Інші кафедри / готовий розклад**

Для кожної дисципліни видно:
- викладачів;
- скільки пар уже внесено;
- скільки це академічних годин;
- скільки видів занять.

Ці години НЕ входять у кафедральне навантаження наших викладачів.

## Редагування готових пар

На картці дисципліни є:
**Редагувати пари**

Відкривається список усіх дат цієї дисципліни:
- дата;
- пара;
- вид;
- викладач;
- аудиторія.

Кожен запис можна:
- редагувати;
- видалити.

## Зовнішні викладачі

Якщо у «Внести готові пари» введено нове ПІБ:
- автоматично створюється зовнішній викладач;
- запис отримує teacherId;
- викладач з’являється в «Викладачах»;
- у його картці видно фактичні дисципліни, групи, кількість пар та академічні години;
- є кнопка «Розклад».

Старі готові записи з ПІБ теж автоматично підтягуються до зовнішніх профілів.

## Компактне навантаження

Дисципліни тепер ідуть двома картками в ряд на широкому екрані.

Одна дисципліна = одна кольорова гама.
Якщо викладачів 2–3:
- вони показуються окремими плашками;
- плашки використовують тільки різні відтінки кольору цієї дисципліни;
- немає різнобарвного «світлофора».
