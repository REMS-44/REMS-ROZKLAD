# РЕМС-РОЗКЛАД v1.3.0 — індивідуальні та консультації

## Новий окремий розділ
У меню «Розклад» додано **Індивідуальні**.

Всередині три режими:
- Індивідуальні заняття
- Консультації бакалаврів
- Консультації магістрів

## Час
Це не загальний парний розклад.

Один запис:
- один конкретний студент;
- одна академічна година;
- половина звичайної пари.

При створенні вибирається:
- студент;
- дата;
- номер пари;
- І половина або ІІ половина;
- аудиторія (необов’язково).

Час половини пари автоматично розраховується з «Розкладу дзвінків».

## Як це пов’язано з навантаженням
Спеціальний розклад використовує те саме розподілене навантаження викладача.
Кожен запис списує **1 годину** з відповідного виду занять.

Спеціальні записи:
- мають власний окремий розклад;
- видно в індивідуальному розкладі викладача;
- займають викладача;
- займають аудиторію, якщо вона вказана;
- не відображаються у загальному розкладі групи;
- не змішуються із журналом звичайних кафедральних пар.

Для двох спеціальних занять різних студентів одна група не блокується цілком.
Але спеціальне заняття не можна поставити студентові під час звичайної пари його групи.

## Додаткові види занять у «Навантаженні»
У картці дисципліни додано блок **Додаткові види занять**.

Можна додати, наприклад:
- Індивідуальне;
- Консультація;
- інший вид із системного довідника.

Ці години:
- входять у загальне навантаження дисципліни;
- розподіляються між викладачами;
- не змінюють вихідний робочий навчальний план;
- не зникають при синхронізації дисципліни з планом.
