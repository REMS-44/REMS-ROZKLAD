# РЕМС-РОЗКЛАД v0.3

Додано:
- випадаючі списки для посади, вченого звання, наукового ступеня;
- почесне звання;
- для звання/ступеня/посади можна вибрати «Інше…» і ввести власне значення;
- структуровані недоступні та бажані дні/години викладача;
- під час створення заняття система перевіряє:
  - зайнятість аудиторії;
  - зайнятість групи;
  - накладку викладача;
  - недоступний час викладача;
  - максимум занять викладача на день.

Замініть у GitHub:
`index.html`, `styles.css`, `app.js`, `data.js`.
