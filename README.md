# РЕМС-РОЗКЛАД v0.9.9 — чиста навігація + готовий розклад

## Ліва панель
Основне меню скорочено до робочих процесів:

ГОЛОВНА

ПЛАНУВАННЯ
- Навчальні плани
- Навантаження

РОЗКЛАД
- Складання розкладу
- Розклад
- Аудиторії

ЛЮДИ
- Групи і студенти
- Викладачі

Внизу:
- Налаштування

## Що об'єднано
- «Групи» + «Студенти» → одна вкладка **Групи і студенти**.
- «Зайнятість аудиторій» + довідник аудиторій → один пункт **Аудиторії** з двома внутрішніми режимами.
- «Види занять» і «Користувачі» прибрані з постійної навігації та перенесені в **Налаштування**.

## Готовий розклад
- на новому браузері система намагається вибрати групу, у якої є найближчі заняття;
- якщо на поточному тижні порожньо, це більше не виглядає як поломка;
- показується найближча дата з розкладом і кнопка переходу;
- можна перейти до будь-якої конкретної дати;
- видно кількість подій на поточному тижні;
- остання вибрана група запам'ятовується.
