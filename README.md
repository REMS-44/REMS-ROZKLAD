# РЕМС-РОЗКЛАД v0.8

Головні зміни:
- стара вкладка «Розклад» перейменована на **«Складання розкладу»**;
- додана окрема вкладка **«Розклад»** — тижневий календар конкретної групи;
- календар: дні по горизонталі, номери пар по вертикалі, у клітинці дисципліна / вид / викладач / аудиторія;
- клік по порожній клітинці відкриває створення заняття на конкретну дату й пару;
- клік по заняттю відкриває редагування;
- у складанні розкладу навантаження показується окремим рядком для конкретного викладача;
- кнопка **«Розставити години»** одразу створює потрібну кількість рядків для всього залишку: кожен рядок має власну дату, номер пари й аудиторію;
- у формах вибирається **номер пари**, а не вручну початок/кінець;
- розклад дзвінків редагується в «Налаштуваннях»; зміна часу пари автоматично оновлює всі заняття, прив’язані до номера цієї пари;
- залишився режим «За правилом» для щотижневих/черезтижневих повторів.

Оновлення GitHub Pages: замінити `index.html`, `styles.css`, `app.js`, `data.js`.
Дані з v0.7 мігрують автоматично через localStorage.
