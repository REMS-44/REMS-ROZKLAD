# РЕМС-РОЗКЛАД v0.5

Ключова зміна: **робочий навчальний план тепер є першоджерелом**.

Додано робочий план 3 курсу «Режисура естради і шоу» на 2026/2027 н.р.:
- 75 кредитів;
- 2250 загальних годин;
- 718 годин за видами аудиторних занять;
- 726 планових аудиторних годин;
- 202 лекційних;
- 14 семінарських;
- 368 практичних;
- 122 лабораторних;
- 12 індивідуальних;
- 1112 самостійної роботи;
- 420 годин практики.

План розбитий на:
- обов’язкові компоненти загальної підготовки;
- обов’язкові компоненти професійної та практичної підготовки;
- вибіркові компоненти;
- 5 і 6 семестри окремо;
- форми контролю;
- усі види аудиторних годин.

Для кафедральних дисциплін є кнопка **«У навантаження»**:
вона створює дисципліну для РЕМС-44 та/або РЕМС-34 з точними годинами із плану.
Після цього вже можна розподіляти години між викладачами.

Загальноосвітні дисципліни зберігаються у плані, але не створюють кафедральне навантаження автоматично.

Для оновлення GitHub Pages замініть:
`index.html`, `styles.css`, `app.js`, `data.js`.
