REMS-ROZKLAD v2.0.9 — SPLIT INDIVIDUAL HOURS

1. Індивідуальні години одного студента можна розподіляти між кількома викладачами.
2. Додано teacherStudentHours: точний розподіл годин викладач → вид → студент → години.
3. Для індивідуальних занять контролюється загальний план на студента, а не ексклюзивність викладача.
4. Бакалаврські та магістерські роботи залишилися ексклюзивними: один студент → один керівник.
5. Спеціальний розклад використовує саме частку годин конкретного викладача для конкретного студента.
6. Старі закріплення індивідуальних студентів автоматично трактуються як повний план на студента у того викладача, за яким вони були закріплені.
7. Додано .nojekyll для стабільної прямої публікації статичного сайту на GitHub Pages.
